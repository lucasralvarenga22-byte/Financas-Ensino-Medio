# 🚀 Como Adicionar Arquivos ao Repositório

## 📌 O que você vai aprender neste guia

Como adicionar seus próprios arquivos .md ao repositório de duas formas:
1. ✅ **Via GitHub Website** (mais fácil)
2. ✅ **Via Aplicativo Dio** (para aprender Git)

---

# 📱 MÉTODO 1: Adicionar via GitHub Website

## Passo 1: Ir ao Repositório

1. Abra seu navegador
2. Digite este endereço:
```
https://github.com/lucasralvarenga22-byte/Financas-Ensino-Medio
```
3. Ou clique aqui: [Abrir Repositório](https://github.com/lucasralvarenga22-byte/Financas-Ensino-Medio)

---

## Passo 2: Clicar em "Add file"

1. Procure o botão verde **"Add file"** (no topo direito)
2. Você verá duas opções:
   - **Create new file** (criar arquivo novo)
   - **Upload files** (enviar arquivo já feito)

```
┌─────────────────────────────────┐
│ 📁 Code  ⭐ Star  🔔 Watch       │
│  ▼ Add file                      │
│    └─ Create new file            │
│    └─ Upload files               │
└─────────────────────────────────┘
```

---

## Opção A: CRIAR NOVO ARQUIVO

Se você quer escrever o arquivo direto no GitHub:

### Passo 1: Clique em "Create new file"

### Passo 2: Nomeie o arquivo

Na primeira linha, escreva:
```
MEU_EXERCICIO.md
```

**Importante:** Termine sempre com **.md**

### Passo 3: Escreva seu conteúdo

Na área branca grande, escreva seu arquivo. Exemplo:

```markdown
# Meu Orçamento Pessoal

## Minhas Receitas

- Mesada: R$ 200
- Trabalho: R$ 300
- Total: R$ 500

## Meus Gastos

- Lanche: R$ 50
- Cinema: R$ 30
- Total: R$ 80

## Minha Sobra

R$ 500 - R$ 80 = R$ 420 ✅
```

### Passo 4: Commit (Salvar)

Na parte inferior, você verá:

```
┌─────────────────────────────┐
│ Commit new file             │
│                             │
│ Commit message:             │
│ [Create MEU_EXERCICIO.md]   │
│                             │
│ Extended description (opt.) │
│ [Meu primeiro exercício]    │
│                             │
│ [Commit directly...] ✅     │
└─────────────────────────────┘
```

**Faça assim:**
1. Escreva uma mensagem simples (já vem pronta)
2. Clique em **"Commit directly to main branch"** (Verde)

**Pronto! Seu arquivo está salvo!** ✅

---

## Opção B: ENVIAR ARQUIVO JÁ PRONTO

Se você já fez o arquivo no Word, Google Docs ou bloco de notas:

### Passo 1: Converter para .md

**Se está em Word:**
- Salve como .txt
- Renomeie extensão de .txt para .md

**Se está em Google Docs:**
- Download > Markdown (.md)

**Se está em Bloco de Notas:**
- Salve como → Type: All Files → nome.md

---

### Passo 2: Clique em "Upload files"

1. GitHub website > Add file > Upload files
2. Clique em **"choose your files"** (ou arraste)

```
┌────────────────────────────────────┐
│ Drag files here to add to your     │
│ repository                         │
│ or choose your files               │
│ [Choose Files]                     │
└────────────────────────────────────┘
```

---

### Passo 3: Selecione seus arquivos

1. Clique em "Choose Files"
2. Procure o arquivo .md no seu computador
3. Clique em abrir

---

### Passo 4: Commit (Salvar)

Na parte inferior:

```
┌──────────────────────────────────┐
│ Commit changes                   │
│                                  │
│ Commit message:                  │
│ [Add files via upload]           │
│                                  │
│ Extended description (opt.):     │
│ [Meu exercício de orçamento]     │
│                                  │
│ ☑ Commit directly to main branch │
│                                  │
│ [Commit changes] (Verde)         │
└──────────────────────────────────┘
```

1. Coloque uma mensagem (ex: "docs: adicionar meu orçamento")
2. Clique em **"Commit changes"** (Verde)

**Pronto! Seu arquivo está no repositório!** ✅

# 📲 MÉTODO 2: Adicionar via Aplicativo Dio

## O que é Dio?

**Dio** é um aplicativo da Digitalização de Inovação que ajuda você a:
- 📱 Estudar online
- 💻 Fazer projetos
- 📊 Usar Git e GitHub
- 🤝 Conectar com comunidade

---

## Passo 1: Fazer Login na Dio

1. Abra o aplicativo Dio (ou site www.dio.me)
2. Clique em **"Login"**
3. Use sua conta:
   - Email da sua conta GitHub
   - Senha do Dio
4. Ou clique **"Continuar com GitHub"**

---

## Passo 2: Procurar o Repositório

1. No Dio, clique em **"Meus Repositórios"** ou **"Projetos"**
2. Procure: **"Financas-Ensino-Medio"**
3. Se não aparecer, clique em **"Importar Repositório"**
4. Cole o link:
```
https://github.com/lucasralvarenga22-byte/Financas-Ensino-Medio
```

---

## Passo 3: Abrir no Git

1. Quando o repositório aparecer, clique em **"Abrir no Git"** ou **"Clonar"**
2. Escolha onde salvar na seu computador
3. Exemplo: `C:\Users\SeuNome\Projetos\Financas`

---

## Passo 4: Editar Arquivos Localmente

Agora você tem o repositório no seu computador!

### Use um Editor (escolha um):

**Opção 1: Visual Studio Code (recomendado)**
- Download: https://code.visualstudio.com/
- Abra a pasta do repositório
- File > Open Folder > Escolha a pasta Financas

**Opção 2: Bloco de Notas**
- Clique direito no arquivo
- Abrir com > Bloco de Notas

**Opção 3: GitHub Desktop (mais fácil)**
- Download: https://desktop.github.com/
- Abra o repositório
- Edite os arquivos

---

## Passo 5: Criar Novo Arquivo .md

### No Visual Studio Code:

1. Clique em **File > New File**
2. Escreva seu conteúdo:

```markdown
# Meu Exercício de Finanças

## Meu Orçamento

Receita: R$ 500
Despesa: R$ 80
Sobra: R$ 420
```

3. Salve como **MEUARQUIVO.md**

---

## Passo 6: "Committar" Mudanças

### No GitHub Desktop:

1. Abra GitHub Desktop
2. Clique em **"Current Repository"** > Escolha seu repositório
3. Você verá seus arquivos modificados
4. Selecione os arquivos que quer enviar
5. Escreva uma mensagem (ex: "Adicionar meu orçamento")
6. Clique em **"Commit to main"**
7. Clique em **"Push origin"** (enviar para GitHub)

```
┌─────────────────────────────────┐
│ GitHub Desktop                  │
│                                 │
│ Current Repository: Financas... │
│                                 │
│ ✅ MEU_EXERCICIO.md (modified)  │
│ ☑ TESTE.md (modified)          │
│                                 │
│ Summary: Adicionar exercícios   │
│                                 │
│ [Commit to main]   [Push origin]│
└─────────────────────────────────┘
```

**Pronto! Seu arquivo está no repositório online!** ✅

---

### No Visual Studio Code:

1. Instale extensão **GitHub Copilot** ou **Git Graph**
2. Clique na aba **Source Control** (esquerda)
3. Você verá seus arquivos modificados
4. Clique em **+** para adicionar os arquivos
5. Escreva mensagem
6. Clique em **✓** (commit)
7. Clique em **↑** (push - enviar)

# 📝 EXEMPLO PRÁTICO COMPLETO

## Vamos fazer seu primeiro arquivo juntos!

### O que você vai criar:
Um arquivo chamado **MEU_ORCAMENTO.md** com seu orçamento real

### Conteúdo do arquivo:

```markdown
# 💰 Meu Orçamento Pessoal

## Informações
- Nome: João Silva
- Data: Setembro de 2026
- Objetivo: Controlar meus gastos

## Minha Receita Mensal

| Fonte | Valor |
|---|---|
| Mesada | R$ 200 |
| Trabalho | R$ 300 |
| **TOTAL** | **R$ 500** |

## Meus Gastos Mensais

| Categoria | Valor |
|---|---|
| Alimentação | R$ 100 |
| Diversão | R$ 80 |
| Tecnologia | R$ 50 |
| Outros | R$ 70 |
| **TOTAL** | **R$ 300** |

## Resultado

Receita: R$ 500
Gastos: R$ 300
**Sobra: R$ 200** ✅

## Meu Plano

- Guardar R$ 150 em poupança
- Deixar R$ 50 para surpresas
- Neste mês: Poupei! 🎉
```

### Passos para enviar:

1. **Via Website:**
   - GitHub.com > Seu repositório
   - Add file > Create new file
   - Nome: MEU_ORCAMENTO.md
   - Copie o conteúdo acima
   - Commit changes

2. **Via Dio + GitHub Desktop:**
   - Abra GitHub Desktop
   - Crie o arquivo MEU_ORCAMENTO.md
   - Escreva o conteúdo
   - Commit to main
   - Push origin
   - Pronto!
